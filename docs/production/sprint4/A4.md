## Tafsiran dan tampilan

"Kota tua" = kota di dalam tembok. Konsekuensi fisik, tidak disulap utuh:
- **Menara lonceng runtuh**: sprite menara, lonceng, portcullis, satu sipres dan satu pohon oak penghalang disembunyikan (view mencari Image `town_aveloria` menurut nama frame + posisi di `scene.children.list`; tanah baking tidak berubah, bayangan menara lama tertutup decal tanah reruntuhan). Diganti: tunggul menara bergerigi (~85 px) + timbunan batu/genteng/balok, atap kerucut jatuh, muka jam pecah (berhenti pukul sembilan), **lonceng perunggu retak tergeletak** (dapat diperiksa), balok, pecahan di halaman, **pagar darurat** (palang silang di sisi barat, pagar datar di sisi selatan), tanda "TUTUP" (dapat dibaca), penjaga di pagar, **debu** naik pelan (2 emitor x 4 frame, piksel opak 3 warna).
- **Kota kosong dan dijaga**: warga grafis lama tersembunyi, tanpa arus warga; penjaga di gerbang dalam (tidak dapat diajak bicara) dan penjaga di pagar. Jalan utama gerbang -> avenue -> istana tetap terbuka (diuji).
- **Retakan mereda**: tidak ada efek krisis Bab III (batu melayang, api beku, jam tersendat, bayangan salah arah, panji berputar, lonceng salah waktu). Tersisa 3 **bekas retakan tenang** (celah gelap + bibir pucat + inti emas redup yang jarang, bukan neon) di lokasi retakan lama dan 6 batu yang sudah kembali ke tanah dengan bayangan datar.
- **Penampungan di luar gerbang selatan** (padang rumput; walkable tambahan di `C4_WALKABLE`): 2 tenda krem berpelana, tenda terpal, tenda kecil, api masak (3 pose), tikar + selimut, 2 orang tidur, 3 kelompok duduk berselimut, karung/peti, gerobak berisi, tong air, tanah terinjak. **Papan daftar warga**, **meja Azie** (buku catatan, tinta, pena). Talric, Azie, Velthia berdiri di sekitar meja; Derrria (NPC bernama C09) di penampungan barat. Suasana: lega yang letih, bukan pesta.
- Senja pelan: tween alfa `0 -> 0.16` setelah `returnSeen` dan `0.2` setelah `complete`; muat langsung dari save = keadaan akhir tanpa tween.
- Oak di (470,1370) disembunyikan agar kanopinya tidak menutupi penampungan; walkable timur dibatasi x <= 896 agar tidak masuk di bawah kanopi oak (960,1340).

Velthia **berdiri sebagai NPC mitra** di meja (tidak mengikuti pemain): dengan begitu interaksi penutup selalu tersedia dan tidak bergantung pada logika pengikut. Torvan tidak hadir.

## Alur cerita (flag di-commit SESUDAH dialognya; dapat dilanjutkan dari tengah)
```
returned (lead)  -> onStart: {c4 returnOpen} -> C4_RETURN_AVELORIA (N) -> setFlag returnSeen -> objective
returnSeen       -> jelajah + percakapan opsional (Talric, Azie, Derrria, 6 warga, lonceng, tanda, papan arah) — tanpa flag
returnSeen       -> bicara Velthia (C4_AVE_VELTHIA_CLOSE) ATAU periksa papan daftar (C4_AVE_ROSTER_CLOSE) -> setFlag chapter.4_complete (SEKALI) -> objective
complete         -> interaksi penutup lagi hanya dialog singkat (tanpa setFlag); onStart [] (tidak memutar ulang)
```
Sebelum `returnSeen`, menemui Talric/Azie/Velthia memainkan adegan kembali (tanpa koreografi kamera) — pengaman bila pemain memotong. Papan daftar sebelum adegan = toast. Tidak ada hadiah/battle/changeArea. Story tidak pernah men-set `C4.returned` (milik lead). Objective (Jurnal saja): "Temui Talric, Azie, dan Velthia di tempat penampungan…" -> "Tutup hari ini: bicara dengan Velthia atau periksa papan daftar warga…" -> "Bab IV selesai."

## Batas dan kekurangan jujur
- **Tidak diverifikasi di browser**: kamera, tween senja, animasi debu/api, penyembunyian sprite dasar lewat `scene.children.list` (nama frame + posisi), dan collision dinamis hanya diuji dengan scene tiruan dan render statis. Perlu satu pass visual oleh lead pada 1366x768 dan 1920x1080 (cek: 5 sprite dasar benar-benar hilang, `debug().hiddenBase.length === 5`).
- Seni DRAFT: reruntuhan lebih kecil dan lebih rendah dari menara aslinya (~140 px -> tunggul ~85 px); tunggul sebagian tertutup kanopi pohon sekitar. Orang duduk/tidur sederhana (wajah 2 titik, dua variasi tidur hanya beda warna selimut); tenda terpal (`tent_b`) berbentuk datar. Warga interaktif memakai sprite warga krisis Bab III (9 varian code-native yang sama; berdiri, idle 2 frame) karena tidak ada sprite duduk; mereka berpindah hadap perlahan tetapi tidak berjalan.
- Bayangan baking pohon yang disembunyikan (sipres dan oak) tetap ada di tanah dasar (tidak mengubah file tanah lama); terlihat sebagai noda gelap kecil.
- Debu tidak punya blur/alfa halus (sengaja, standar CHAPTER12): terbaca sebagai butir piksel, bukan kabut.
- Velthia tidak mengikuti pemain; Talric/Azie tidak berjalan (diam di titik adegan).
- Dialog `chapter4.aveloria.ts` seluruhnya DRAFT_IMPL untuk review manusia; hanya portrait yang sudah ada yang dipakai (C01 NEUTRAL/SAD/DETERMINED, C02 NEUTRAL/AMUSED, C05 NEUTRAL/SKEPTICAL/WORRIED, C06 NEUTRAL, C09 AMUSED/WORRIED).
- Tidak ada SFX/BGM baru; `AWAITING_COMPOSER` tidak berubah.
