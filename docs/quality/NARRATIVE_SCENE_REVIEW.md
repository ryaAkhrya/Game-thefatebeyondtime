# NARRATIVE SCENE REVIEW — REVISI 02

Setiap scene sebelum dimasukkan game perlu dibaca dan dicoba manusia. Ini daftar **quality gate**, bukan pengganti review.

- **Karakter:** Apakah Yaric terasa spontan, Velthia seorang ratu yang punya keputusan, Torvan jahil namun tidak membocorkan jati diri, Varlgrim berduka dan salah tafsir bukan kartun jahat?
- **Motivasi:** Apakah tiap scene punya alasan tindakan nyata, bukan sekadar melontarkan tema 'takdir'?
- **Bahasa:** Semua dialog Indonesia natural untuk kerajaan; tidak pidato puitis, tidak slang internet, tidak kalimat 'wahai' berulang.
- **Causality:** Segel Heart sumber retakan; bukti dari Chapter III, pengungkapan lengkap IV. Lonceng, lambang, evakuasi punya payoff.
- **Chronology:** Chapter IV memori kuno Aveloria saja. **Modern berabad-abad kemudian dalam M-01..M-03.** Epilog tebing flashback setelah itu. Masa lalu tidak melihat foto masa depan.
- **Sisi pribadi:** Dialog memori yang menyebut kenangan nyata adalah placeholder dan harus diisi Game Director; tidak boleh mengarangnya.
- **Implementasi:** Story flag selesai sekali, skip/load tidak double reward, text speed dan reduced motion/flash setting berlaku, tombol keyboard bisa lanjut.
- **Visual:** Sprite/asset placeholder jelas, review skala native, tidak ada efek AI-slop.

Mark `PASS` hanya sesudah pemeran/dialog/visual diuji di browser. Draft script v1.x tidak otomatis menjadi final hanya karena ada file `.md`.
