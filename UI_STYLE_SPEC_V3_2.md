# UI identity v3.2 — DRAFT visual direction

Seven full-screen 320×180 pixel layout mockups enlarged 3× with nearest-neighbor are under `assets/ui/v3_2/`. They replace the inherited four simple wireframes as the current design examples; old mocks remain as v3.1 history. A paired broken arc and interrupted frame edges signal two timelines nearly meeting. Deep Plum `#3B2A4A`, Bitter Lime `#C7D96A`, warm text and restrained rose accents. Original concept art remains the identity reference.

| Screen | Interaction and proof in mockup | Pending acceptance |
|---|---|---|
| Title | Broken motif; New Game/Continue/Settings | motion, disabled Continue, focus loop |
| Dialogue | C01 expression PNG, speaker, text and advance hint | multiline/wrapping, more speakers, screen reader text |
| Battle | HP/MP, five actions and lime selected focus | target selection, status icons, contrast at native 1× |
| Pause | Resume, Inventory, Save, Settings, Return | safe focus restore and skip policy |
| Inventory | item list, details, Use/Back | item types, equipment and keyboard scrolling |
| Save | local slot, chapter and confirmation | multiple slots, error/corruption recovery |
| Settings | all 9 GDD controls including Reduced Flashes ON | actual implementation/persistence and input test |

Keyboard: arrows move focus, Enter confirms, Escape backs out, visible lime focus border; do not trap focus. Pixel perfect or Fit preserving 16:9. At 1×, 8px labels require usability review on desktop displays; mockups are not game UI code. Reduced Flashes defaults ON as in the GDD and Screen Shake can be disabled. Music files remain AWAITING_COMPOSER, silent fallback. No Persona-like menu imitation or dashboard layout.
